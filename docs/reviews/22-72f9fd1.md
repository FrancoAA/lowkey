# Review 22 — uncommitted work on top of 72f9fd1 (who is speaking)

After Stop, the others in a call are told apart by voice (sherpa-onnx: pyannote segmentation
3.0 + TitaNet-S), each "Them" line gets Speaker 1, 2…, and the user names them (the same name
merges two). Off by default; turning it on downloads 46 MB. The computer's sound is kept in a
temporary file until then. Measurements: docs/voices.md.
Reviewer: DeepSeek V4.1 Flash (`opencode/deepseek-v4.1-flash`, variant high), read-only via
T3 Code `delegate_task`, told never to run the app, Hyprland, audio commands, xdg-open or the e2e.
Verdict: "a careful, well-scoped implementation and the happy path is sound … I found no
blocking bug in the ordinary record → stop → labels → rename flow. The weaknesses are at the
edges."

| # | Finding | Outcome |
|---|---|---|
| 1 | The whole tape read into memory 3× its size; a long meeting could end the app after Stop | Fixed: read in pieces into one buffer; meetings over 3 hours keep "Them" (the file is dropped while it records); silence is a hole in the file, not bytes (test) |

| 6 | A panic in the pass left the meeting "working" for good, with no note save or AI notes | Fixed: a guard ends "working" also after a panic; the error is shown; the note and the notes follow |
