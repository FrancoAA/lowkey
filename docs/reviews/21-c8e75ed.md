# Review 21 — uncommitted work on top of c8e75ed (fix the transcript)

A click on a paragraph of a saved meeting fixes its text or its speaker; a fix that looks like a
name or a term offers to add it to the Vocabulary; Write notes again after a fix.
Reviewer: DeepSeek V4.1 Flash (`opencode/deepseek-v4.1-flash`, variant high), read-only via
T3 Code `delegate_task`, told never to run the app, Hyprland, audio commands or the e2e.
Verdict: "The core of the feature is sound and the index model is safe as long as the page keeps
showing the meeting it rendered … Nothing blocks shipping, but #1–#5 are worth fixing."

| # | Finding | Outcome |
|---|---|---|
| 1 | An edit was posted with the meeting shown at save time, not the one whose lines it had | Fixed: the edit keeps its meeting's id; opening another meeting or the list ends it |
| 2 | Notes written while a fix landed, or in the same second, counted as fresh | Fixed: a transcript version and the version the notes were written from |

| 7 | No offer for names in scripts without case | Fixed: a letter that is not lower case, or a digit (tests; a Chinese phrase without spaces is offered whole) |

| 9 | The speaker switch could lose the focus race | Fixed: the switch never takes the focus from the text |
