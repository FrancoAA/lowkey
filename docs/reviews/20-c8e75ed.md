# Review 20 — uncommitted work on top of c8e75ed (note apps, strip fixes, e2e crash fixes)

Note apps (each meeting as Markdown in a chosen folder: Obsidian, Logseq, synced folders), the
strip fixes (active meeting over a finished dictation's message, hold while the cursor is on the
saved strip, focus back without moving the cursor, Open the notes in front), and the e2e fixes
(a test D-Bus without services, no ANR dialog, `LIBSEAT_BACKEND=seatd`, cleanup of the run's
own programs).
Reviewer: DeepSeek V4.1 Flash (`opencode/deepseek-v4.1-flash`, variant high), read-only via
T3 Code `delegate_task`, told never to run the app, Hyprland, audio commands, xdg-open or the e2e.
Verdict: "The design is sound … But there are two defects I would fix before merging (a
cross-thread export race, and a 255-byte filename overflow), plus the note-app paths are
effectively broken on Windows."

| # | Finding | Outcome |
|---|---|---|
| 1 | Two exports of one meeting (after Stop, after the AI notes) could interleave: shared temp name, hash stored apart from the file → the note frozen as "changed outside" | Fixed: one lock over load → write → hash; a unique temp name (test: four saves at once) |
| 2 | Names cut at 80 characters, not bytes: a long CJK/emoji title → ENAMETOOLONG on every save | Fixed: a 200-byte budget for the title (test) |
| 3 | Windows: `start` split the obsidian:// link at `&`; times in UTC | Link fixed (quoted with `raw_arg`); the time zone stays UTC on Windows for now (meetings record on Linux only) |
| 4 | A new line in a title (from `--title` or an agent) broke the YAML front matter | Fixed: control characters escaped (test) |
| 5 | If the focus failed, `cursor:no_warps` could stay on in the user's session | Fixed: `pcall` around the focus; the reset always runs (checked in the nested Hyprland) |
| 6 | Title and notes edits did not reach the note | Fixed: saved 3 s after the last edit |
| 7 | The offset of "now", not of the meeting (summer time) | Fixed: `date -d @<start> +%z` (test with Europe/Madrid in July and November) |
| 8 | No fsync before the rename | Fixed: `sync_all`, then rename, then the folder |
| 9 | Toolbar buttons did not follow a Settings change; Open in Obsidian for a note in a former folder | Fixed: the view refreshes with the status; the meeting keeps the folder it was saved in |
| 10 | A typo in `export_parts` dropped parts silently | Fixed: names in any case |
| 11 | `export_file` could name a path outside the folder (not exploitable) | Fixed: only its file name is used |

Checked after the fixes: 127 unit tests; the full e2e (`E2E DESKTOP OK`) with the note-folder
checks; the session unchanged, nothing left running, no core dumps.
